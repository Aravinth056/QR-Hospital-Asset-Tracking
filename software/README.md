# Software

## 📌 Overview

This folder contains the software-related files and documentation for the **Intelligent Hospital Asset Tracking and Management System**.

The system is developed as a browser-based web application using **Python Flask** and **SQLite**.

---

## 💻 Technology Stack

| Technology | Purpose |
|---|---|
| Python | Backend programming |
| Flask | Web application framework |
| SQLite | Database management |
| HTML | Web page structure |
| CSS | Interface design |
| JavaScript | Frontend interaction |
| QR Code | Asset identification |
| Browser Camera | QR scanning |

---

## ⚙️ Main Software Functions

The software provides:

- User login
- Role-based access
- Asset registration
- Asset identification
- QR-code scanning
- Asset Take operation
- Asset Return operation
- Asset Transfer operation
- Damage reporting
- Asset availability monitoring
- Delayed-return monitoring
- Maintenance tracking
- Transaction history
- Messaging
- Emergency information
- Management reports
