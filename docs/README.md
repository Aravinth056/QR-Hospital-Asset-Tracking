# Documentation

## 📌 Overview

This folder contains the technical documentation of the **Intelligent Hospital Asset Tracking and Management System**.

The project, called **Asset Track**, uses QR-code scanning, a Python Flask backend, and an SQLite database to manage reusable hospital assets through a browser-based system.

## 📚 Documentation

This folder contains the following documents:

- `System-Overview.md` – Overall system design and major features
- `Working-Principle.md` – How the asset tracking system works
- `Methodology.md` – System development and operational methodology
- `Future-Scope.md` – Possible future improvements
